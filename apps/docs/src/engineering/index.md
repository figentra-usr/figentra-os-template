# Engineering

This is the general engineering folder — process notes, conventions, and how-we-work documents that apply across the codebase but aren't a hard standard (that's `engineering/standards/`) and aren't about the SDLC machinery itself (that's `engineering/system/`). Think onboarding notes, tooling walkthroughs, or "how we do code review" style pages.

Anyone on the engineering team can add a page here; there's no single owner. Keep pages short and dated where the content is likely to drift (tool versions, workflow steps) so readers can tell at a glance whether a page is still current.

**Nothing has been written here yet.** Add pages as real engineering conventions emerge — this folder exists so there's a home for them rather than have them accumulate as tribal knowledge.
