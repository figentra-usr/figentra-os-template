# Legacy

Legacy holds documentation from a previous system, previous stack, or previous era of the project that is no longer current but is worth keeping for context — why something was built the way it was, what an old process used to look like. It is read-only: nobody edits a legacy page to bring it up to date, because its entire value is being an accurate record of the past. Where a legacy document conflicts with anything in Platform, Products, or Decisions, the current documentation wins.

**Nothing has been migrated here yet.** This is a blank template with no prior system to carry forward; this folder exists so there's a designated, clearly-labeled home for that material on the day this project's own "legacy era" begins.
